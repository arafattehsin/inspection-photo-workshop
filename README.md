# Inspection photo workshop

A technician attaches a photo of a damaged conveyor guard to an inspection report. The tablet displays **Photo saved**, so the technician closes it. At shift handover, the supervisor opens the report and finds that the photo is missing.

This repository contains the fictional report used in the workshop. Read the technician’s issue and its follow-up comment to find out what the supervisor wants the app to display. [Open the technician’s report](https://github.com/arafattehsin/inspection-photo-workshop/issues/1)
